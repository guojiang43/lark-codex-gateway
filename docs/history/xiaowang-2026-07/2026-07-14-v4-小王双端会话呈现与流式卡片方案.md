# 小王双端会话呈现与流式卡片方案 v4

- 日期：2026-07-14
- 版本：v4
- 文档类型：产品与技术方案
- 前置方案：`2026-07-13-v3-小王双主机执行架构.md`

## 1. 结论

产品目标不是让飞书复制一份 Codex 文本，而是让同一个 Codex thread 在两个界面中各自用合适的方式呈现：飞书负责远程输入、进度和最终答案，MacBook Codex Desktop 负责完整任务记录、继续对话和本地工作。

当前采用两阶段实现：

1. 当前降级态：M4 保持唯一飞书入口，MacBook 独立 app-server 执行；turn 写入同一个持久 thread，但当前 Desktop 窗口不保证刷新；
2. 目标形态：MacBook 官方 managed daemon/control socket 就绪后，M4 通过 `app-server proxy` 连接，并让 Desktop 设置 `CODEX_APP_SERVER_USE_LOCAL_DAEMON=1` 接入同一控制面，实现 Desktop 实时可见。

任何时候 `proxy` 不可用，都必须自动退回第一阶段，不得让飞书入口或 MacBook 执行能力整体离线。

## 2. 消息生命周期

```text
飞书消息
  -> M4 唯一网关
  -> 选择 M4 / MacBook execution host
  -> Codex thread/turn
     -> commentary：运行中显示在流式卡片
     -> reasoning：不向飞书展示
     -> final_answer：替换 commentary
  -> 卡片结束流式，只保留最终答案
  -> MacBook Desktop 打开/重载同一 thread
```

关键规则：

- `item/started` 决定 agent message 的 `itemId` 与 `phase`；delta 本身不能承担阶段判断；
- 同一个 item 内原样累加，不同 item 之间插入空行；
- 首个 `final_answer` 到达即清空过程区，后续只累计最终答案；
- `turn/completed` 只负责结束状态，不再决定正文内容；
- 最终卡片不保留“停止生成”和 Session 选择按钮。

## 3. Desktop 可见性的产品口径

### 当前上线口径

飞书任务完成后，网关会尝试打开对应 Codex task，但 2026-07-14 的真实验收已证明：当 task 已在当前窗口打开时，深链返回成功也不会可靠重载外部 app-server 写入的新 turn。因此这只能保留为无害的 best-effort 行为，不能作为产品承诺。

### 完整目标口径

当官方 managed daemon/control socket 可用时，网关优先通过：

```text
codex app-server proxy
```

连接 Desktop 所在控制面。此时飞书触发的 turn 与 Desktop 使用同一内存事件源，Desktop 可实时看到任务状态。

当前 MacBook 缺少官方 managed standalone，不能把“安装并启动成功”写成既成事实。系统会记录降级原因并自动使用稳定回退链路；稳定回退只指任务可以执行和落盘，不包含 Desktop UI 自动可见。

## 4. 验收标准

- 飞书生成过程中，两个 commentary item 之间有可见空行；
- 最终答案出现后，过程文字从原卡片消失；
- 完成态卡片只保留最终答案，停止按钮消失；
- raw thread ID 不变，MacBook Desktop 打开的是本轮实际执行的 task；
- Desktop 不在线或 control socket 不存在时，MacBook 执行链路仍可用；
- M4 始终是唯一飞书 WebSocket 消费者；MacBook 休眠不影响 M4 收消息和切回 M4。

## 5. 后续升级闸门

只有以下条件全部满足，才把 `proxy` 从“优先尝试”升级为“强制依赖”：

1. 官方 managed standalone 已安装；
2. daemon/control socket 可由 LaunchAgent 稳定恢复；
3. M4→MacBook SSH 下 `initialize`、`thread/list`、`thread/resume` 和真实 turn 均通过；
4. Desktop 在不执行 `open codex://...` 的情况下实时出现远端 turn；
5. 睡眠、断网、Desktop 退出和升级后能自动恢复；
6. 失败时仍能自动退回独立 stdio，不丢消息、不重复执行。
